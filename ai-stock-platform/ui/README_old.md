# QuantumVestAI UI

![QuantumVestAI Logo](static/img/logo.svg)

A modern web interface for stock market forecasting and analytics using quantum machine learning models.

## Features

- **Stock Forecasting**: Predict stock price movements with multiple forecasting models
- **Model Comparison**: Compare performance of different forecasting algorithms
- **Predictability Analysis**: Assess how predictable a stock is before investing
- **Watchlist Management**: Track and monitor your favorite stocks
- **Market Insights**: Get real-time market updates and news
- **Responsive Design**: Optimized for desktop and mobile devices

## Tech Stack

- **Framework**: FastAPI
- **Templates**: Jinja2
- **Styling**: Bootstrap 5 with custom CSS
- **Charts**: Chart.js
- **Icons**: Bootstrap Icons
- **API Client**: Custom client for QuantumVestAI API
- **Authentication**: JWT + Cookie-based sessions
